# BetterPOV for Fabric 1.21.11

A Minecraft 1.21.11 port of SpectatorPlus for Fabric, maintained for the BetterPOV project.

The mod improves spectator POV by synchronizing and displaying the spectated player's hotbar, health, food, experience, held items, inventory, and supported container screens.

Based on [hpfxd/SpectatorPlus](https://github.com/hpfxd/SpectatorPlus), licensed under GPL-3.0-or-later.
